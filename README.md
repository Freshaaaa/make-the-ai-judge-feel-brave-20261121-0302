## The text

The program `main.ts` (Node 22, no dependencies, no network) writes this text to `/output/entry.txt`:

```
The river moves.
The stone does not.

It lets the water pass.
It stays.

Cool. Certain. Still.

You are the stone.
The river is only passing.
```

Run it with `node main.ts`.
